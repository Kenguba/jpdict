# 2026-10-14 搜索、OCR 与词库加载验证

工程规范仍以根 README 为唯一来源；本文记录本次实现、根因和实际验证。

## 最终行为

- 语言按钮默认显示“混合”，选择后直接显示当前语言；长按显示混合、韩语、日语、英语四项；持续按住滑到选项并松手提交，也可点击。先读持久偏好，再发布同进程共享状态；退出 App 和进程重启后恢复上次选择及按钮文字。混合使用四脚本，固定语言仅调用对应模型；预览和局部精读锁定同一语言。
- 英语模式在 Android 7.0+ 提供英文 `imeHintLocales`，已聚焦时刷新输入法；其他模式清除提示。保留普通多行输入、发送键、私密标志和 Unicode，不启用 FORCE_ASCII、不更换系统输入法。Android 6.0 保持普通输入。自动切换取决于输入法是否响应 [Android 的语言提示接口](https://developer.android.com/reference/android/view/inputmethod/EditorInfo#hintLocales)，应用不限制用户手动换语言。
- 单击浮球打开搜索；普通拖动移动并保存位置，已授权时识别取词，未授权时只移动。静止长按 700ms 后四向滑动只显示方向 Toast；旧普通滑动 Toast 分支保留注释。
- 快捷入口为搜索词库、词库管理、悬浮按钮设置、设置。搜索词库与输入框按钮共用提交方法，设置复用抽屉设置路由。
- 新复制文字换行追加到已有输入，保持原文；同一复制事件不重复追加，保留两分钟过滤。只在搜索窗口有焦点时监听，查词、失焦和销毁时注销。完整输入作为额外候选，短项进入三列，长/多行项在顶部满宽显示；显示省略不截断查询内容。
- 网页 Token 输入失败的根因是 WebView 不可聚焦及 Overlay 的 NOT_FOCUSABLE 标记。现在先确认点击命中可编辑 DOM，再临时聚焦窗口、聚焦原字段并建立原生 IME 连接。普通文本和 readonly 不进入编辑；隐藏、切词、关闭及失焦清理编辑。保留原字段类型，不读取生产字段值、不增加 Bridge。编辑期间一次返回关闭键盘和查词窗口。

## 词库首次慢的原因与改动

原控制器同时排队所有默认展开词库，同级任务后进先出，后排反而抢先；未就绪正文也已展开。解析器池在全局锁内打开文件、计算首尾指纹和冷解析，每个 CSS、图片、字体请求重复做这些操作，两个工作线程可能被串行化。窗口内正文缓存随关闭丢失，两解析器被多本 MDX/MDD 淘汰后需要重复查询。

首本及可见分区现在按显示顺序优先，显式操作继续保持最新操作优先；后排默认展开每次只延迟加载一本。加载前收起，主页面完成后再按保存意图或用户点击展开；离屏正文不创建 WebView。保留两个解析器、三个 WebView 和 96 个排队任务上限。

新增跨窗口正文缓存，按 URI、文件代次或指纹及原始查询区分，上限 2 MiB / 64 项。私有不可变安装代次通过 URI/mtime/大小快速命中，外部文件继续核对指纹，未知修改时间不复用；原有持久索引仍有效。冷解析和指纹移出池全局锁，驻留私有解析器借用不重复打开文件。窗口结果被驱逐后可见时能重载，后台不立即重载以避免缓存抖动。

模拟器一轮 30 本原创小样本查询测得首次约 27.05ms、缓存约 0.80ms；此为缓存前后单次测量，不是旧实现与新实现的完整基准，也不代表商业词库或实体手机耗时。真实大正文、图片、字体、首次逐块验证及不可复用的外部文件仍有读取成本。下载目录原实现仍为 PREVIEW，本次优化针对安装后本地读取，没有新增网络下载器。

## 验证

JDK 17.0.20.1、Gradle 8.11.1、compileSdk 35，API 37.2 ARM64 模拟器。设备测试使用隔离的 `com.yuen.jpdict.oct14qa` 应用 ID 和原创文件，未修改原应用词库或读取真实 Token/剪贴板。

| 验证 | 结果 |
| --- | --- |
| 独立 MDX/MDD 引擎 | 2,623 条断言通过 |
| 正文缓存 | 12 条断言通过 |
| 调度 | 队列容量、两线程、取消、可见 FIFO、同级 P0 再次操作优先通过 |
| Android 词库集成 | 61 条断言通过，包括未加载收起、页面就绪展开、跨解析器淘汰缓存、同 mtime 外部变化失效及离屏结果滚入重载 |
| OCR 手势 | 35 条断言通过 |
| 语言、输入法、快捷入口、剪贴板和候选 | 168 条断言通过，模型 process 调用计数使用平台代理，不依赖模型下载 |
| HTML 输入 | 16 条断言通过，包括系统 IME 实际可见、明文提交、textarea/contenteditable、readonly/普通文本及一次返回 |
| 搜索状态与外观配置 | 状态检查及 126 条外观断言通过 |
| arm、arm64、armv7 Debug 构建与 Lint | 全部通过，各 0 errors / 101 warnings；含 WebView 原生触摸转发的 ClickableViewAccessibility 提示 |

已用独立 QA 包核对无缓存默认显示“混合”，通过实际长按菜单选择“日语”后磁盘偏好为 japanese；终止 QA 进程并冷启动后按钮仍显示“日语”。

三个 Debug APK 约 4.27 MiB，未新增第三方依赖。原生界面已核对四项语言菜单、已有模型菜单下的持续滑选、未授权拖动、700ms 上滑 Toast、快捷入口顺序及长输入满宽候选。

本次没有重测真实 OCR 字体精度、OriginOS 实机或 Android 6.0–7.x。没有发布 Release、提交或推送；保留任务开始前已有的外观文件修改及 README 注释。
