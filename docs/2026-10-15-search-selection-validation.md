# 选词、搜索返回及键盘稳定性修复

## 根因与实现

- OCR 原先初选整词后，只要跨过字符边界就转成累计字符范围，落点移动和轻微抖动也会取到碎片。现在初次落点及单向移动保持完整词，真正折返后才按真实字符轨迹选择。相邻字符边界统一按左上包含、右下排除，线段仅擦到边缘不算经过，正向、反向及竖排共享边界有回归覆盖。
- 指针原先直接挂载、移除窗口；现在 140ms 淡入淡出，退场用 Picture 保留当时画面，新手势清掉旧画面并接管，关闭立即清理。方向圆环退出后才请求截图，延迟请求校验当前识别会话。
- 候选控制器每次输入及查词返回先清空，视图随后全部重建；大爆炸也先退回无匹配状态。现在保留已有结果直到新结果就绪，按身份复用词块，颜色和新增内容平滑过渡。点击候选直接查询，不再用候选覆盖原输入。
- 大爆炸放到快捷入口下方的键盘预留区域，可被键盘遮挡；移除右侧说明与分页栏。每次最多 48 个词单元的有界匹配任务串行执行，结果按原文范围累积成完整纵向滚动内容，返回保留匹配及滚动位置。
- 输入器图标原先始终创建为闪电；现在读取与菜单、摇杆相同的持久化查询目标，快速为闪电，第三方为连接器。搜索发起第三方查询改由透明宿主先保护返回路径，隐藏并保留同一搜索 View；返回或打开失败后恢复。旧宿主的返回和关闭请求不能操作新会话。
- 缓存高度原先仍被每次 onApplyWindowInsets 立即覆盖，OEM 重复分发的中间值也可能进入缓存；缓存与真实高度不同会瞬间移动输入卡。现在动画期间只记录待确认值，在当前动画结束或连续高度稳定后才提交，渲染预留在 200ms 内平滑校准。取消的旧动画不能提交半高数据。旧 Android 不再跟随每帧可见区压缩预留，键盘回到系统栏基线才释放焦点；打字增加可见行数时卡片高度以 160ms 过渡。

## 验证

使用 API 37.2 模拟器与独立 `com.yuen.jpdict.searchreturnqa` 包，不替换原应用、不修改用户词库。

- 搜索布局 95 条断言通过，包含重复 onApply 中间高度、不污染缓存、动画打断、平滑校准、换行高度过渡、大爆炸位于快捷入口下方、候选视图复用和查询方式图标。
- 真实键盘 12 条断言通过：实际高度校准为 883px 后，连续四轮显隐及三轮打字/候选更新，共 171 个 pre-draw 帧；输入卡屏幕顶部始终 1096px、底部始终 1389px，缓存始终 883px。未用合成 Insets 代替这组真实键盘测量。
- 候选控制器 28 条、输入组合与大爆炸 31 条、页面及宿主返回 34 条、查询目标 82 条设备断言通过。长文测试包含 180 个英文词与末尾日语词，核对完整原文、无分页、末尾可见、滚动及匹配返回保留。第三方成功交接状态由测试模拟，并实际执行宿主保存/重建/返回回调；没有安装或假冒欧路。
- 纯 Java 搜索状态、草稿/分词、OCR 33 条规则、浮球配置 126 条、词典解析 2,646 条及调度/缓存/远程策略检查通过。OCR 定时测试采用消息截止时间与真实时间戳验证重新停留至少 150ms，不再用两个固定 sleep 推断主线程实际经过时间；错误会回到测试线程报告。
- 只读逐块验证 `文稿/japanese/日语单词总汇/日语单词总汇.mdx` 的 2,467,643 个词头；`fath` 能返回 `father` 等候选，`father` 精确查询得到 1 条记录。未改写、提交或复制该词库到发布包。

- 最终设备 OCR 168 条、语言与输入 175 条断言通过，包含十轮独立字符选区、四轮原球/代理交替预览与精读、授权恢复、旧会话隔离、指针动画重入与关闭清理。真实时间戳核对重新停留至少 150ms、授权界面退场至少 300ms。
- 最终三个常规 ABI Debug 构建及 Lint 通过，每项 0 errors / 111 warnings。`arm64` 为 4,615,219 bytes，`armv7` 为 4,615,230 bytes，`arm` 为 4,615,257 bytes，均小于 5 × 1024 × 1024 bytes；项目跟踪文件加本次新增代码及记录约 1.72 MB，低于 35 MiB。
- 本地使用 Java 17.0.20.1、Gradle 8.14.3、Android SDK 35。真实键盘独立 runner 为 `com.yuen.jpdict.SearchKeyboardInstrumentation`，构建时可用 `-PjpdictTestRunner=com.yuen.jpdict.SearchKeyboardInstrumentation`；仍须先设置独立 QA applicationId 和词库 fixture authority，禁止在用户原包运行会创建测试词库的模式。

## 边界

没有目标 vivo/OriginOS 日志，无法断言字符误选是该手机频繁 OCR 失灵的唯一原因。本次设备 OCR 回归使用真实 View、窗口、截图资源与注入的识别结果检查会话和选区，不能作为真实模型精度结论。目标手机、旧 Android 实机、该手机输入法和真实欧路启动返回尚未实测；旧 Android 修改由代码与状态路径核对。首次安装或更换输入法后仍需一次实际高度校准，不能提前知道系统尚未提供的键盘高度。正式版本号、签名及发布 APK 由 main 推送的 GitHub Actions 按 README 校验。
