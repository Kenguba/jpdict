## 本次更新

- 修复拖动停留后偶尔没有启动 OCR：按触摸事件的真实时间计算原有 150ms 门槛，松手时保留已经满足的识别资格，避免主线程积压事件丢失触发。

## 兼容与验证范围

四种脚本模型仍随 APK 安装，保持离线识别、原有语言与查词入口。本次修复交互触发和圆环定位，不改变模型识别算法；两个模型任务持续不回调时的进程级保护限制仍保留，不宣称所有 OCR 故障或字体误识都已解决。针对性回归与未验证范围见[修复验证记录](https://github.com/kenguba/jpdict/blob/main/docs/2026-10-18-ocr-ring-validation.md)。

## 下载

- `arm64-v8a`：推荐现代 ARM 手机。
- `armeabi-v7a`：32 位 ARM 手机。
- `arm`：同时包含以上两种 ARM 架构。

三个 APK 均须低于 30 MiB，使用固定 Release 签名。附件 `SHA256SUMS.txt` 用于完整性校验。
