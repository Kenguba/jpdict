## 本次更新

- 恢复浅色设置页与侧栏原有的灰色背景、搜索页原有的浅色背景，保留深色模式配色。
- 修复动态预览首次进入及滑条归零后无法拖动的问题；整个预览区域可横滑，快速拖动数值滑块也能立即预览，长按拖动仍用于保存宽度。
- 侧边栏三种展开方式都按设置百分比确定实际宽度；每种方式单独保存，重启后仍有效。
- 侧边栏设置页新增可拖动的实时预览，包含双圆环拖动反馈和参考 HTML 的代码动画；阳光随时间移动，随机降雨，水面增加轻柔涟漪并移除瀑布，深色模式下萤火虫增加柔光与亮度。这些效果仅用于设置页预览。
- 调整展开方式卡片、标签、阴影和体验按钮布局。
- 移除动态预览标题右侧的状态文字，并放大金色滑动提示箭头。

## 下载

- `arm64-v8a`：推荐现代 ARM 手机。
- `armeabi-v7a`：32 位 ARM 手机。
- `arm`：同时包含以上两种 ARM 架构。

三个 APK 均须低于 30 MiB，使用固定 Release 签名。附件 `SHA256SUMS.txt` 用于完整性校验。
