Release 工作流负责运行项目测试、三种 ARM ABI 的 Lint 与 Release 构建，并校验 APK 体积、离线 OCR 模型、固定签名、包名/版本及 SHA-256。设备行为以本次工作流结果为准；OriginOS 与旧 Android 真机未实测。

## 下载

- `arm64-v8a`：推荐现代 ARM 手机。
- `armeabi-v7a`：32 位 ARM 手机。
- `arm`：同时包含以上两种 ARM 架构。

三个 APK 均须低于 30 MiB，使用固定 Release 签名。附件 `SHA256SUMS.txt` 用于完整性校验。
