## 本次更新

- 大词条改为后台流式解码与磁盘支持的 HTML 展示，去掉 512 KB 显示和 2 MB 正文查询限制；词库与配套资源采用有界并行验证。
- 词库操作弹窗收紧留白，“后台加载”收成可拖动的全局进度球，点击恢复，完成后显示完成。
- 输入区新增文字大爆炸，本地词库确认存在的单词和词组可以点击查词。
- 新复制文字替换输入全文，被替换草稿保留在淡紫色区域；支持拖到准确光标位置插入，或拖进红色垃圾桶删除。
- 词典网页开启按词库隔离的 DOM 存储，支持网页脚本保存 Token；保留最新返回宿主修复，避免键盘弹出时意外关闭查词窗口。
- 普通拖动在指针停留 300ms 后开始 OCR；捕获会检查当前授权与可用帧，失效时重新申请屏幕共享。
- 长按浮球打开方向摇杆：上方句子 OCR、右侧日语 OCR、下方英语单词 OCR；英语模式过滤中日韩文字，支持指针扫过区域选词。
- 新增 [界面样式规范](https://github.com/Kenguba/jpdict/blob/main/style.md)，统一弹窗、加载球、文字大爆炸与 OCR 手势。

## 兼容与验证范围

MDX/MDD v1/v2、raw/zlib/LZO1X 与原有本地资源隔离继续保留。v3、密码保护与非空 Compact 样式表尚不支持。网页存储修复不代表第三方词库服务器已经验证授权，缺失脚本或在线服务仍需词库作者提供。

OCR 模型通过 Google Play 服务下载；首次使用缺模型时需要联网。模拟器验证不能替代 OriginOS 实机与旧版 Android 验收。

## 下载

- `arm64-v8a`：推荐现代 ARM 手机。
- `armeabi-v7a`：32 位 ARM 手机。
- `arm`：同时包含以上两种 ARM 架构。

三个 APK 均须低于 5 MiB，使用固定 Release 签名。附件 `SHA256SUMS.txt` 用于完整性校验。
