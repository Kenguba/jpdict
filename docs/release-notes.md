## 本次更新

- 长按选择 OCR 时，圆盘固定在浮球周围，手指选择方向不再拖动浮球或改变原取词点。
- 圆盘上方选择句子、右侧选择日语、下方选择中文；左侧仍切换系统或第三方查词。英语模式保留在输入卡片的语言菜单。
- 移除韩文 OCR，改为中文入口。Latin、Chinese、Japanese 三种离线模型仍随 APK 安装；以前保存的韩文模式会回退为混合模式。
- 拒绝通知权限后仍可请求 Android 屏幕共享授权。每次截图与精读都会检查当前共享会话；会话失效时才重新请求系统授权。

## 兼容与验证范围

API 37.2 模拟器的连续查词测试中，英语、日语与句子样本准确返回；同一中文截图在中文模型下三次多出前导竖线 `|`，混合模式对照识别正确。所有 20 轮均走完截图、查词和返回流程，但精确文本匹配为 17/20；这项识别误差尚未解决，也未在红米实体机验证。模型任务持续不回调时的进程级保护仍保留。其他实测与边界见[本轮验证记录](https://github.com/kenguba/jpdict/blob/main/docs/2026-10-18-ocr-modes-permission-validation.md)。

## 下载

- `arm64-v8a`：推荐现代 ARM 手机。
- `armeabi-v7a`：32 位 ARM 手机。
- `arm`：同时包含以上两种 ARM 架构。

三个 APK 均须低于 30 MiB，使用固定 Release 签名。附件 `SHA256SUMS.txt` 用于完整性校验。
