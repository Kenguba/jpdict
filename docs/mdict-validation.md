# 自研词典验证记录

根目录 README.md 是唯一工程规则源；本文件仅记录实现、样本与实测边界。

## 实现与来源

解析核心、LZO 解码和测试文件生成器均为本项目独立编写的 Java，没有复制第三方词典引擎或 LZO 解码器实现。运行时只使用 Java/Android 平台能力，原有 APK 依赖列表不变。

格式研究资料：

- [writemdict 原作者的文件格式分析](https://github.com/zhansliu/writemdict/blob/master/fileformat.md)：读取格式描述，没有复制第三方引擎或加密实现；v2 索引解码由本项目按格式说明独立实现。
- [RIPEMD-128 原作者的数学说明](https://homes.esat.kuleuven.be/~bosselae/ripemd/rmd128.txt)与[官方测试向量](https://homes.esat.kuleuven.be/~bosselae/ripemd160.html)：仅按数学算法独立实现校验和派生密钥，不使用参考 C 实现，不用于应用安全。
- [Linux 内核社区 LZO 字节流说明](https://docs.kernel.org/staging/lzo.html)：仅按字节语法独立实现 LZO1X v0，不使用内核解压代码。
- [mdictlib 作者对 v1 字段差异的记录](https://docs.rs/crate/mdictlib/0.2.2/source/CHANGELOG.md)：确认四个 u32 字段、原始 Key 元数据、一字节摘要长度及无摘要结束符；未采用其解析实现。

公开资料是格式分析，不能视为 MDict 厂商的完整规范。初次实现没有提供实际商业词典样本；后续有限本地样本验证记录见下文，不能据此宣称全部商业词典兼容。

## 对抗式审查与修复

- P1：只用索引首尾词头会在不同排序规则下漏查中间键。改为首次建立实际词头范围并持久缓存，新增反例测试。
- P1：文件覆盖后数据库提交前中断可能损失旧词典。改为不可变文件代次，成功提交后清理旧代次；删除使用可恢复临时目录。
- P1：轻量恢复可能误清理已有内部文件。保留同 ID/指纹的现有文件；新机明确待重新关联。
- P1：资源请求可能跨词典、越界或联网。限制当前 dictId 的本地拦截，禁止路径穿越、文件/内容访问、脚本和 Bridge。
- P1：WebView 把 `loadDataWithBaseURL` 的内联主文档误当资源拒绝。允许自身 data 主文档，其他资源继续隔离；新增真实加载回归测试。
- P1：旧音频任务及旧查询可能更新新窗口。以窗口所有权和音频代次拒绝过期结果，关闭时取消并释放。
- P2：Android 6.0 不支持新增的 Java Stream / Map 默认方法。换成兼容循环与显式 Comparator，未加入 desugaring 依赖。
- P2：极端块/记录/清单可能占用过量内存。加入独立限制、全链重定向预算、有界队列/LRU/解析器、3 个 WebView 上限和大块串行读取。
- P2：无悬浮权限的 Activity 回退页在 Android 15 以上被系统状态栏遮挡。为全屏回退页处理系统栏、刘海和键盘 Insets；模拟器回归同时核对词库列表与管理入口。

## 2026-10-12：Compact 标记误拒绝修复

用户录屏在 SAF 文件夹授权后报“Compact 样式扩展尚不支持”。旧代码仅根据 `Compact/Compat=Yes` 拒绝文件，未区分空 `StyleSheet`。本地 13 本未加密 MDX 均含这一标记和空样式表，修复前全部在文件头校验失败。

在原解析条件上允许缺失、空或仅空白的样式表，释义不做替换；非空样式表继续明确拒绝。某些本地词库的索引首尾摘要还会按发布方规则去掉 ASCII 标点、空格或转为小写，例如 `12 a.m` 对应 `12am`。摘要比较沿用文件大小写标记，并仅在 `StripKey/Stripkey=Yes` 时去掉 ASCII 标点与空格；实际词头、精确查询、块范围缓存和资源路径规则不变，真正不符的摘要仍拒绝。

JDK 17、`-Xmx128m`：13 本 MDX 全部逐块校验成功，并执行一次 `test` 查询。其中 12 本返回词条，汉英反查词库返回空结果；本次仅核对读取成功，没有核对所有释义、样式或附属资源。本地样本涵盖韦氏高阶、牛津同义/商务/搭配、ODE 2nd / 2024、剑桥英汉、牛津搭配汉英反查、文馨/新时代颜氏反查、柯林斯第八版双解反查、牛津第四版双解反查及 lasd。原始词库与释义未纳入仓库或 APK。

## 2026-10-12：大小写重定向、资源与查询速度

用户指定本机“优词英语词源词典 (一缕清风, 2026-02-06) 紧凑版”和“例解学習漢字辞典［第九版］”目录作为验证样本。旧引擎对日语单词总汇的 `my` 查询复现循环错误：存在正文键 `my` 和别名键 `MY -> @@@LINK=my`；按规范化词头判定循环会将合法大小写别名当作循环。重定向现在优先寻找目标的原始大小写，仅在缺失时回退到文件规定的大小写比较；顶层查询仍保留全部匹配和重复记录，真实循环、深度与结果预算继续报错。

原验证完成后未保存查询索引，首次查词会重扫全部词头；范围重叠也会造成大量无关 Key Block 解压。导入现在按最终 URI、指纹与实际文件修改时间保存验证索引，并增加合计最多 2 MiB 的 Bloom 摘要；过滤只排除不可能的块，实际匹配仍检查原词头。辅助索引格式升级为 JPD3，旧缓存自动重建，不修改原词库。

## 2026-10-12：OALDPE 下载尾部与内容自适应
