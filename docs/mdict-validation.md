# 自研词典验证记录

根目录 README.md 是唯一工程规则源；本文件仅记录实现、样本与实测边界。

## 实现与来源

解析核心、LZO 解码和测试文件生成器均为本项目独立编写的 Java，没有复制第三方词典引擎或 LZO 解码器实现。运行时只使用 Java/Android 平台能力，原有 APK 依赖列表不变。

格式研究资料：

- [writemdict 原作者的文件格式分析](https://github.com/zhansliu/writemdict/blob/master/fileformat.md)：读取格式描述，没有复制第三方引擎或加密实现；v2 索引解码由本项目按格式说明独立实现。
- [RIPEMD-128 原作者的数学说明](https://homes.esat.kuleuven.be/~bosselae/ripemd/rmd128.txt)与[官方测试向量](https://homes.esat.kuleuven.be/~bosselae/ripemd160.html)：仅按数学算法独立实现校验和派生密钥，不使用参考 C 实现，不用于应用安全。
- [Linux 内核社区 LZO 字节流说明](https://docs.kernel.org/staging/lzo.html)：仅按字节语法独立实现 LZO1X v0，不使用内核解压代码。
- [mdictlib 作者对 v1 字段差异的记录](https://docs.rs/crate/mdictlib/0.2.2/source/CHANGELOG.md)：确认四个 u32 字段、原始 Key 元数据、一字节摘要长度及无摘要结束符；未采用其解析实现。

公开资料是格式分析，不能视为 MDict 厂商的完整规范。初次实现没有提供实际商业词典样本；后续有限本地样本验证记录见下文，不能据此宣称全部商业词典兼容。

独立调度测试阻塞两个工作线程后提交 30 本词典，验证展开第 30 本的 P0 提升、P1 排序、取消和 96 个排队上限。

## 实测性能与 Android 验证

2026-10-12，本机 JDK 17，`-Xmx128m`：2,181,044,649 字节稀疏 MDX 只读取 4,489 字节，冷打开/查询单次约 0.72 ms。此样本仅用于验证 64 位偏移与按需读取，不代表真实大型商业词典的索引建立耗时。

API 37.2 ARM64 模拟器、原创小词典：一次冷导入/查询 23.48 ms，一次热查询 0.38 ms；30 本注册后的 Java 堆增量 6,864,896 字节。均为单次实测，非性能保证；完整验证新增后导入需要逐块验证，其耗时与词库大小相关。

平台 Instrumentation 的 31 条断言覆盖：内部导入、独立副本、原文件删除、重复拒绝、MDD 编号分卷、CSS、重命名与开关持久化、同机轻量恢复保留文件、新机轻量恢复待关联、完整恢复、备份穿越拒绝/失败保持旧数据、SAF 可 seek 描述符、管道拒绝、取消、外部解除关联不删除原始文件、外部缺失提示、30 本注册与重排、示例 Catalog、WebView 安全设置/主文档加载/内部跳转/跨词典隔离、关闭后的异步 UI 拒绝。

三 ABI Debug 构建和 Lint、既有搜索状态测试和悬浮按钮配置测试通过。正式发布由 main 的 GitHub Actions 以固定证书构建并另行校验实际 APK 体积和签名。

模拟器手工回归确认：MDD CSS 与词条 HTML 在悬浮和无悬浮权限回退页显示；查词顶栏列表能进入词库管理；从搜索查词进入管理后返回保留搜索草稿；回退 Activity 沿用既有 `noHistory` 行为，打开管理后退出管理会回到调用方；示例下载页明确显示不可下载。

## 对抗式审查与修复

- P1：只用索引首尾词头会在不同排序规则下漏查中间键。改为首次建立实际词头范围并持久缓存，新增反例测试。
- P1：文件覆盖后数据库提交前中断可能损失旧词典。改为不可变文件代次，成功提交后清理旧代次；删除使用可恢复临时目录。
- P1：轻量恢复可能误清理已有内部文件。保留同 ID/指纹的现有文件；新机明确待重新关联。
- P1：资源请求可能跨词典、越界或联网。限制当前 dictId 的本地拦截，禁止路径穿越、文件/内容访问、脚本和 Bridge。
- P1：WebView 把 `loadDataWithBaseURL` 的内联主文档误当资源拒绝。允许自身 data 主文档，其他资源继续隔离；新增真实加载回归测试。
- P1：旧音频任务及旧查询可能更新新窗口。以窗口所有权和音频代次拒绝过期结果，关闭时取消并释放。
- P2：Android 6.0 不支持新增的 Java Stream / Map 默认方法。换成兼容循环与显式 Comparator，未加入 desugaring 依赖。
- P2：极端块/记录/清单可能占用过量内存。加入独立限制、全链重定向预算、有界队列/LRU/解析器、3 个 WebView 上限和大块串行读取。
- P2：无悬浮权限的 Activity 回退页在 Android 15 以上被系统状态栏遮挡。为全屏回退页处理系统栏、刘海和键盘 Insets；模拟器回归同时核对词库列表与管理入口。

## 2026-10-12：Compact 标记误拒绝修复

用户录屏在 SAF 文件夹授权后报“Compact 样式扩展尚不支持”。旧代码仅根据 `Compact/Compat=Yes` 拒绝文件，未区分空 `StyleSheet`。本地 13 本未加密 MDX 均含这一标记和空样式表，修复前全部在文件头校验失败。

在原解析条件上允许缺失、空或仅空白的样式表，释义不做替换；非空样式表继续明确拒绝。某些本地词库的索引首尾摘要还会按发布方规则去掉 ASCII 标点、空格或转为小写，例如 `12 a.m` 对应 `12am`。摘要比较沿用文件大小写标记，并仅在 `StripKey/Stripkey=Yes` 时去掉 ASCII 标点与空格；实际词头、精确查询、块范围缓存和资源路径规则不变，真正不符的摘要仍拒绝。

JDK 17、`-Xmx128m`：13 本 MDX 全部逐块校验成功，并执行一次 `test` 查询。其中 12 本返回词条，汉英反查词库返回空结果；本次仅核对读取成功，没有核对所有释义、样式或附属资源。本地样本涵盖韦氏高阶、牛津同义/商务/搭配、ODE 2nd / 2024、剑桥英汉、牛津搭配汉英反查、文馨/新时代颜氏反查、柯林斯第八版双解反查、牛津第四版双解反查及 lasd。原始词库与释义未纳入仓库或 APK。

独立解析测试共 2,362 条断言，新增空/缺失/空白样式表、Compact 与 Compat 两种标记、v1/v2、三种压缩、UTF-8/UTF-16LE、跨块 Unicode、重复/空词条、重定向、二进制资源、规范化摘要、错误摘要及精确查询边界；非 ASCII 标点不会被摘要规范化移除。持久索引复用路径使用含空 Compact 样式表及 Encrypted=2 索引的原创样本。

API 37.2 ARM64 模拟器平台集成测试 31 条断言通过：内部导入、外部关联、重复拒绝及完整/轻量备份恢复等既有路径改用带空 Compact 样式表的原创 MDX，以及 Encrypted=2 的原创 MDD。三个常规 ABI 的 Debug 构建、Lint、搜索状态及悬浮按钮配置测试通过。Git 跟踪的项目文件约 0.72 MiB，三个 Debug APK 各约 4.09 MiB，均在 README 体积限制内；正式签名及体积由 main 的发布流水线另行校验。

用户随后提供开发目录中的“朗文当代高级英语辞典6th”作为实际验证样本：`/Users/ken/开发/欧陆词典测试 暂时 准备删除/朗文当代高级英语辞典6th.mdx`（114,117,946 bytes，162,014 个词头）及 `/Users/ken/开发/朗文当代高级英语辞典6th/朗文当代高级英语辞典6th.mdd`（91,120,710 bytes，1,467 个资源）。MDX 为 Encrypted=0；MDD 为 Encrypted=2，旧引擎会误将其与需要密码的文件一起拒绝。

新增独立、小型的 MdictIndexDecoder，在现有解压前原地解码 v2 索引，不复制整个文件、不新增依赖。压缩类型、Adler32、块/索引上限与取消检查继续生效。RIPEMD-128 的 9 个官方向量（含跨块和百万字符）全部通过，原创 MDX/MDD 混淆样本、重定向、损坏和取消检查通过；密码保护 Encrypted=1/3 及未知方式继续拒绝。

本机 128 MiB Java 堆逐块校验朗文 MDX/MDD 均成功；`test / hello / world / information` 各返回一个词条，MDD 的 `img/encn/information.jpg` 返回 74,080 bytes。样本需要同目录的 `src/lm6.css` 外部样式表；该 MDD 不含所核对的发音路径 `media/english/ameProns/test1.mp3`，不据此宣称该样本发音可用。JavaScript 仍不执行。

在 API 37.2 模拟器以 SAF 递归文件夹执行真实内部导入，MDX、MDD 和 lm6.css 共约 205 MB，列表显示安装成功；通过正式 Deep Link 查询 `information`，核对悬浮小窗中释义、CSS 样式和 MDD 图片实际显示。测试前备份模拟器词库记录，测试后恢复；原始 Mac 词库未改动。

录屏中的“日语单词总汇”原始 MDX 尚未提供，不能从报错画面判断其 StyleSheet 是否为空，也不能宣称该原始词库已导入成功。非空 Compact 样式表仍未支持。
