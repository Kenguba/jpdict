# 自研词典验证记录

根目录 README.md 是唯一工程规则源；本文件仅记录实现、样本与实测边界。

## 实现与来源

解析核心、LZO 解码和测试文件生成器均为本项目独立编写的 Java，没有复制第三方词典引擎或 LZO 解码器实现。运行时只使用 Java/Android 平台能力，原有 APK 依赖列表不变。

格式研究资料：

- [writemdict 原作者的文件格式分析](https://github.com/zhansliu/writemdict/blob/master/fileformat.md)：读取格式描述，没有使用其中的加密实现或项目代码。
- [Linux 内核社区 LZO 字节流说明](https://docs.kernel.org/staging/lzo.html)：仅按字节语法独立实现 LZO1X v0，不使用内核解压代码。
- [mdictlib 作者对 v1 字段差异的记录](https://docs.rs/crate/mdictlib/0.2.2/source/CHANGELOG.md)：确认四个 u32 字段、原始 Key 元数据、一字节摘要长度及无摘要结束符；未采用其解析实现。

公开资料是格式分析，不能视为 MDict 厂商的完整规范。没有提供实际商业词典样本，兼容性结论仅限以下原创样本与路径。

## 原创样本矩阵

`tests/MdictReaderTest.java` 在临时目录生成合法数据，释义、资源和 LZO 向量均属于本项目原创测试内容。没有将第三方词库打包进 APK。

| 版本 | 文件 | 编码 | 数据块 | 结果 |
| --- | --- | --- | --- | --- |
| 1.2 | MDX | UTF-8 / UTF-16LE | raw / zlib / LZO1X v0 | 通过 |
| 2.0 | MDX | UTF-8 / UTF-16LE | raw / zlib / LZO1X v0 | 通过 |
| 1.2 / 2.0 | MDD | UTF-16LE | raw / zlib / LZO1X v0 | 通过 |
| 2.0 | MDX | UTF-8 | 约 2.03 GiB 稀疏 raw 数据 | 64 位随机访问通过 |
| 其他 1.x / 2.x、GBK、GB18030、Big5、UTF-16BE | 解析分支存在 | 尚无真实样本 | 未验证 | 不宣称通过 |
| v3、加密、密码、Compact、LZO-RLE | 明确拒绝/不支持 | — | — | 不宣称兼容 |

独立测试共 1,799 条断言，包含多 Key/Record Block、跨块 Unicode、重复键、空记录、大小写、不同排序方式、MDD 图片/CSS/音频/字体字节、重定向与循环、校验、截断、异常压缩长度、持久索引复用/损坏重建/指纹变化、关闭、取消和 1,000 个固定种子随机坏输入。

LZO 向量包含短/长 literal、尾随字节、M2/M3/M4、重叠回溯、短匹配、非法回溯、截断、错误输出长度和未消费尾部。MDD 音频/字体测试主要确认字节正确，尚未据此证明全部字体或音频编解码器兼容。

另外使用 [LZO 2.10 官方压缩器](https://www.oberhumer.com/opensource/lzo/) 对三组原创 65,536 字节内容生成独立参考压缩数据；自研解码器逐字节恢复通过。压缩工具仅在工作区外用于生成测试数据，没有将其源代码、库或可执行文件纳入工程、依赖或 APK；向量来源和校验值见 `tests/vectors/README.md`。

独立调度测试阻塞两个工作线程后提交 30 本词典，验证展开第 30 本的 P0 提升、P1 排序、取消和 96 个排队上限。

## 实测性能与 Android 验证

2026-10-12，本机 JDK 17，`-Xmx128m`：2,181,044,649 字节稀疏 MDX 只读取 4,489 字节，冷打开/查询单次约 0.72 ms。此样本仅用于验证 64 位偏移与按需读取，不代表真实大型商业词典的索引建立耗时。

API 37.2 ARM64 模拟器、原创小词典：一次冷导入/查询 23.48 ms，一次热查询 0.38 ms；30 本注册后的 Java 堆增量 6,864,896 字节。均为单次实测，非性能保证；完整验证新增后导入需要逐块验证，其耗时与词库大小相关。

平台 Instrumentation 的 31 条断言覆盖：内部导入、独立副本、原文件删除、重复拒绝、MDD 编号分卷、CSS、重命名与开关持久化、同机轻量恢复保留文件、新机轻量恢复待关联、完整恢复、备份穿越拒绝/失败保持旧数据、SAF 可 seek 描述符、管道拒绝、取消、外部解除关联不删除原始文件、外部缺失提示、30 本注册与重排、示例 Catalog、WebView 安全设置/主文档加载/内部跳转/跨词典隔离、关闭后的异步 UI 拒绝。

三 ABI Debug 构建和 Lint、既有搜索状态测试和悬浮按钮配置测试通过。正式发布由 main 的 GitHub Actions 以固定证书构建并另行校验实际 APK 体积和签名。

模拟器手工回归确认：MDD CSS 与词条 HTML 在悬浮和无悬浮权限回退页显示；查词顶栏列表能进入词库管理；从搜索查词进入管理后返回保留搜索草稿；回退 Activity 沿用既有 `noHistory` 行为，打开管理后退出管理会回到调用方；示例下载页明确显示不可下载。

## 对抗式审查与修复

- P1：只用索引首尾词头会在不同排序规则下漏查中间键。改为首次建立实际词头范围并持久缓存，新增反例测试。
- P1：文件覆盖后数据库提交前中断可能损失旧词典。改为不可变文件代次，成功提交后清理旧代次；删除使用可恢复临时目录。
- P1：轻量恢复可能误清理已有内部文件。保留同 ID/指纹的现有文件；新机明确待重新关联。
- P1：资源请求可能跨词典、越界或联网。限制当前 dictId 的本地拦截，禁止路径穿越、文件/内容访问、脚本和 Bridge。
- P1：WebView 把 `loadDataWithBaseURL` 的内联主文档误当资源拒绝。允许自身 data 主文档，其他资源继续隔离；新增真实加载回归测试。
- P1：旧音频任务及旧查询可能更新新窗口。以窗口所有权和音频代次拒绝过期结果，关闭时取消并释放。
- P2：Android 6.0 不支持新增的 Java Stream / Map 默认方法。换成兼容循环与显式 Comparator，未加入 desugaring 依赖。
- P2：极端块/记录/清单可能占用过量内存。加入独立限制、全链重定向预算、有界队列/LRU/解析器、3 个 WebView 上限和大块串行读取。
- P2：无悬浮权限的 Activity 回退页在 Android 15 以上被系统状态栏遮挡。为全屏回退页处理系统栏、刘海和键盘 Insets；模拟器回归同时核对词库列表与管理入口。
