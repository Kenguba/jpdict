## 动效

- 随时打断：可被手势或操作打断的动画须可取消、可重定向；动画进行中收到新操作时从当前位置就地转向新目标，不从头重播、不等播完才响应；不用不可打断的一次性关键帧序列跑完才停（对应 Web 的 transition 优于 @keyframes 的原则）。既有「新手势可打断并接管」「收起与恢复沿目标球位置执行动画」与此一致，继续适用。
- 轻轻退场：弹窗、浮层等退场只移出一小段（约 20–50dp）即同步淡出并加轻微模糊，位移、透明度、模糊一起收尾；不把元素一路飞出屏幕。
- 柔和切换：内容或图标切换用交叉淡化，叠加轻微缩放与模糊过渡；不瞬时显隐硬切。
- 入场缓出：入场动画用强缓出曲线（等价 cubic-bezier(.16, 1, .3, 1)），快起慢收；不用匀速或线性，匀速看着像机器。
- 分组高亮滑动：分组导航的移动高亮，组内切换滑动跟随；跨组切换不滑动、不扫过无关项，旧高亮淡出、新高亮淡入；用 View Transitions 时每组用不同的 view-transition-name 区分。
- 验收方式：动效改完用录屏回放加慢动作逐帧自查，并与速度、位置曲线对比；只凭正常速度肉眼看一遍不算验收。
